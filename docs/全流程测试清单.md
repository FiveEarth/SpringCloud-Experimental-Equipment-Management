按顺序测试以下接口与前端按钮，确保无报错。网关端口默认 8888，前端开发 8080 并代理到 8888。

## 一、设备删除错误（已修复）

- **问题**：批量删除设备时报错 `Cannot delete or update a parent row: a foreign key constraint fails (lab_equipment_asset, fk_asset_equipment)`。
- **修复**：删除设备前先删除该设备类型下所有实例（`lab_equipment_asset`），再删除 `lab_equipment`。
- **若仍报错**：说明该设备存在**预约 / 领用 / 报修 / 报废**记录，后端会返回 400 并提示“请先取消预约/完成归还或处理后再试”，前端会弹出该提示。

## 三、常见错误与处理

- **400 参数错误**：预约/领用必填项未填；看后端或前端提示补全。
- **403 没有权限**：请求头未带 X-Roles（管理员/教师接口）；登录后由前端统一加请求头。
- **404**：请求未走网关或路径写错；确认前端 baseURL/代理到 8888，路径为 /api/xxx。
- **500 且含 SQL 外键**：多为“先删父表”或“存在关联记录”；设备删除已改为先删 asset，若仍有预约/领用等会返回 400 提示。
- **日期/时间显示 1970**：预约开始/结束为 TIME 类型，前端已用 formatReserveTime(reserveDate, time) 拼接显示。
- **请求头非 ISO-8859-1**：中文姓名导致 setRequestHeader 报错；已在拦截器中对 X-User-Name、X-Roles 做安全编码。
