本项目基于 Spring Cloud 的微服务架构，面向实验室场景实现设备、预约、申领、维修、报废及实验室资源等业务的一体化管理。
后端采用 Java 17、Spring Boot 3 与 Spring Cloud Alibaba，通过 Nacos 做服务发现与配置中心，Sentinel 做流量防护，各业务域独立部署；
使用 Spring Cloud Gateway 作为统一入口，结合 JWT 实现全局鉴权，并将用户标识、角色与权限写入请求头，供下游服务消费。
服务间通过 OpenFeign 调用，设备等服务集成 Redis 缓存以减轻数据库压力。
前端为 Vue 3 + Element Plus 的单页应用，按角色（如管理员、教师、学生、维修人员）划分路由与功能模块，覆盖审批、统计、设备台账与维修工单等页面。
